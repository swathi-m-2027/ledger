# Ledger — Personal Finance Analytics
React + Node/Express + PostgreSQL. See DEPLOY steps in the chat: Neon (database) -> GitHub -> Render (website).

Render build command:  cd frontend && npm install --include=dev && npm run build && cd ../backend && npm install
Render start command:  cd backend && npm start
Environment variables: DATABASE_URL (from Neon), APP_PASSWORD (your own password)
